## 1. COC 2 Discussion 1 Pre-test — proposed 3 questions

**Source:** learning-content/COC-2/Lesson-01/01-Pretest.md

**Mapping rationale:** Items 1, 2, and 4 are the source questions directly about basic network concepts and device roles (LAN, switch, and router). The instructor-only mapping assigns items 3, 5, 6, 7, 9, and 10 to Discussion 2 (network setup, addressing, cabling, and security), and item 8 to Discussion 3 (testing and interpreting ping). This preserves the approved mapping; no questions were added or rewritten. The resulting three-question Discussion 1 set is a short starter assessment and does not cover every documented Discussion 1 topic, so confirm its adequacy or request additional reviewed items before activation.

### Student-facing questions

1. What does LAN stand for?
   - A. Local Area Network
   - B. Large Access Node
   - C. Linked Application Number
   - D. Long Area Network

2. Which device commonly connects several wired devices within the same LAN?
   - A. Modem
   - B. Switch
   - C. Printer
   - D. Repeater only

4. What is the main purpose of a router?
   - A. Print documents
   - B. Connect different networks and route traffic
   - C. Increase monitor resolution
   - D. Store user files

### Instructor-only answer key and explanations

**1. A. Local Area Network**
Explanation: LAN means Local Area Network, a network connecting devices within a limited site such as a home or school.

**2. B. Switch**
Explanation: A switch connects multiple wired devices on the same local Ethernet network and forwards their frames.

**4. B. Connect different networks and route traffic**
Explanation: A router forwards traffic between distinct networks, such as a local network and an upstream internet network.

## 2. COC 1 Generalized Post-test — 10 questions

**Competency:** COC 1 — Computer Systems Servicing NC II

**Source:** learning-content/assessments/generalized-post-tests/coc1-generalized-post-test.md

**Passing threshold:** 70% (unchanged).

### Student-facing questions

1. A customer requests a repair estimate. Which approach is most appropriate?
   - A. Start work before discussing the likely cost
   - B. Quote a price without checking the required parts or labor
   - C. Assess the task, estimate parts and labor, explain uncertainty, and obtain approval before chargeable work
   - D. Add unrelated services to increase the total

2. Which component executes program instructions?
   - A. CPU
   - B. Keyboard
   - C. SSD
   - D. Monitor

3. Which action helps reduce electrostatic discharge risk while handling computer components?
   - A. Touch component contacts with bare fingers
   - B. Use an ESD-safe work area and a properly used wrist strap
   - C. Work on carpet while wearing wool
   - D. Place components on a metal table without protection

4. What is the safest first step before opening a desktop case for service?
   - A. Remove the CPU cooler while the computer is running
   - B. Open the power supply enclosure
   - C. Pull on the motherboard cables
   - D. Shut down, disconnect power, and follow the service procedure

5. A technician is asked to reinstall an operating system, and the selected drive may contain user files. What should happen first?
   - A. Delete every partition to save time
   - B. Begin installation and ask about files later
   - C. Confirm authorization, identify the correct drive, and back up required data
   - D. Disable the monitor

6. A student uses DiskPart while preparing a USB drive. Which precaution is most important?
   - A. Assume DiskPart recognizes the intended drive automatically
   - B. Select the first disk in the list every time
   - C. Disconnect the keyboard during formatting
   - D. Verify the selected disk by size and identity because disk commands can erase data

7. Which statement about GPT and MBR is the most accurate for an installation plan?
   - A. GPT is required for every computer, including all legacy BIOS systems
   - B. MBR always supports every modern UEFI installation
   - C. GPT is commonly paired with UEFI and MBR with legacy BIOS, but the actual target and vendor instructions must be checked
   - D. The choice never affects booting

8. After installing an operating system, which action best verifies basic setup?
   - A. Assume success because the desktop appeared once
   - B. Remove every driver
   - C. Disable updates and stop documenting
   - D. Check activation/licensing as applicable, device status, updates, drivers, and required application operation

9. A PC shuts down during a combined CPU/GPU test. Which conclusion is best supported by that observation?
   - A. The motherboard is definitely defective
   - B. The system passed because it started
   - C. The user must replace the computer immediately
   - D. The test observed instability under those conditions; record it and investigate cooling, power, settings, and hardware before retesting

10. A burn-in test completes for 30 minutes with no reported errors. What is the most accurate report statement?
   - A. The system can never fail
   - B. No errors were observed during the selected 30-minute test conditions; this does not prove the system is fault-free
   - C. Every component is certified defect-free
   - D. No further documentation is needed

### Instructor-only answer key and explanations

**1. (Easy) — C. Assess the task, estimate parts and labor, explain uncertainty, and obtain approval before chargeable work**
Explanation: A transparent estimate should be based on the work and expected costs, with customer approval before chargeable work.

**2. (Easy) — A. CPU**
Explanation: The CPU processes instructions; the other options provide input, storage, or output.

**3. (Easy) — B. Use an ESD-safe work area and a properly used wrist strap**
Explanation: ESD controls help equalize charge and protect sensitive components when used correctly.

**4. (Easy) — D. Shut down, disconnect power, and follow the service procedure**
Explanation: Power isolation and the equipment service procedure reduce electrical and hardware risks. A PSU enclosure must not be opened by a student technician.

**5. (Moderate) — C. Confirm authorization, identify the correct drive, and back up required data**
Explanation: Installation or partition changes can destroy data, so authorization, target verification, and backup come first.

**6. (Moderate) — D. Verify the selected disk by size and identity because disk commands can erase data**
Explanation: DiskPart can modify or erase the selected disk; the technician must identify the target carefully and have authorization.

**7. (Moderate) — C. GPT is commonly paired with UEFI and MBR with legacy BIOS, but the actual target and vendor instructions must be checked**
Explanation: The pairing is common, but the supported configuration depends on the system and installation requirements.

**8. (Moderate) — D. Check activation/licensing as applicable, device status, updates, drivers, and required application operation**
Explanation: A post-install checklist verifies that required devices and software work and that relevant updates and licensing are addressed.

**9. (Difficult) — D. The test observed instability under those conditions; record it and investigate cooling, power, settings, and hardware before retesting**
Explanation: A shutdown identifies a reproducible symptom, not a unique root cause. Further controlled diagnosis is required.

**10. (Difficult) — B. No errors were observed during the selected 30-minute test conditions; this does not prove the system is fault-free**
Explanation: Test conclusions must be limited to the conditions and duration actually observed.

- Final question 2 (original draft question 2): Retained to assess a core hardware component and its role in executing instructions.
- Final question 3 (original draft question 4): Retained for essential electrostatic-discharge prevention when handling components.
- Final question 4 (original draft question 5): Retained for safe power isolation before opening equipment.
- Final question 5 (original draft question 7): Retained for authorization, target-drive verification, and protection of customer data before installation.
- Final question 6 (original draft question 10): Retained because DiskPart can erase data, making target identification a critical practical safeguard.
- Final question 7 (original draft question 12): Retained to assess choosing a compatible boot mode and partition style for the actual target system.
- Final question 8 (original draft question 14): Retained for practical post-install verification across devices, drivers, updates, and required operation.
- Final question 9 (original draft question 17): Retained for cautious interpretation of a stress-test shutdown without jumping to an unsupported diagnosis.
- Final question 10 (original draft question 19): Retained to assess accurate reporting whose conclusion is limited to the test conditions.

## 3. COC 2 Generalized Post-test — 10 questions

**Competency:** COC 2 — Computer Systems Servicing NC II

**Source:** learning-content/assessments/generalized-post-tests/coc2-generalized-post-test.md

**Passing threshold:** 70% (unchanged).

### Student-facing questions

1. Which device primarily forwards traffic between different IP networks?
   - A. Patch panel
   - B. Keyboard
   - C. Router
   - D. Cable tester

2. What does DHCP commonly provide to a client automatically?
   - A. A permanent computer repair
   - B. IP configuration such as an address, subnet mask, gateway, and DNS information
   - C. A new network cable
   - D. An encrypted backup of all files

3. Which command displays Windows IP configuration details?
   - A. `ipconfig /all`
   - B. `format`
   - C. `diskpart`
   - D. `dir`

4. What does a cable tester help check on a terminated Ethernet cable?
   - A. Wire continuity and, depending on the tester, pair or pin mapping faults
   - B. Whether a domain name resolves
   - C. Whether an application server is licensed
   - D. The internet provider's billing status

5. Which topology connects endpoint devices to a central switch, making a single endpoint-link fault easier to isolate?
   - A. Bus topology
   - B. Ring topology
   - C. Star topology
   - D. Point-to-point serial chain

6. A workstation needs a manually assigned address. What must be checked before assigning it?
   - A. That it matches another computer's address
   - B. That it is outside every permitted subnet
   - C. The monitor resolution
   - D. The approved subnet plan and DHCP scope, to avoid an address conflict

7. A technician can ping a server by IP address but not resolve its hostname. Which service should be investigated first?
   - A. DHCP lease duration only
   - B. DNS configuration or name records
   - C. Cable color
   - D. Monitor driver

8. Which wireless security choice is generally appropriate for a current home or small-office network when devices support it?
   - A. Open Wi-Fi
   - B. WEP
   - C. TKIP-only mode
   - D. WPA3-Personal, or WPA2-Personal with AES when WPA3 is not supported

9. An authorized network inspection finds link lights on, valid IP configuration, a gateway ping reply, and failed DNS lookup. What is the best next diagnostic step?
   - A. Check the configured DNS server and use `nslookup` to determine whether the query reaches and receives a valid response
   - B. Re-terminate every cable without evidence
   - C. Replace the switch immediately
   - D. Disable all firewall protections

10. A technician needs to test whether users can access a specific file-sharing service. Which approach provides the strongest relevant evidence?
   - A. Ping the gateway once and assume file sharing works
   - B. Test the required service from an authorized client and record the actual result, alongside supporting network checks
   - C. Check whether the switch is new
   - D. Run `ipconfig` and assume every application works

### Instructor-only answer key and explanations

**1. (Easy) — C. Router**
Explanation: A router forwards traffic between networks; a switch commonly connects devices within a LAN.

**2. (Easy) — B. IP configuration such as an address, subnet mask, gateway, and DNS information**
Explanation: DHCP leases IP configuration to clients according to the network's DHCP service.

**3. (Easy) — A. `ipconfig /all`**
Explanation: `ipconfig /all` displays detailed network adapter configuration on Windows.

**4. (Easy) — A. Wire continuity and, depending on the tester, pair or pin mapping faults**
Explanation: Cable testers check physical wiring faults; they do not test every network service.

**5. (Moderate) — C. Star topology**
Explanation: A star connects endpoints to a central device. A failure of the central device can affect many endpoints.

**6. (Moderate) — D. The approved subnet plan and DHCP scope, to avoid an address conflict**
Explanation: Static addresses must fit the network plan and must not conflict with another host or DHCP assignment.

**7. (Moderate) — B. DNS configuration or name records**
Explanation: DNS translates names to IP addresses, so DNS settings and records are relevant to this symptom.

**8. (Moderate) — D. WPA3-Personal, or WPA2-Personal with AES when WPA3 is not supported**
Explanation: Prefer WPA3 when supported; WPA2 with AES is a compatibility fallback. Legacy weak or open modes should be avoided.

**9. (Difficult) — A. Check the configured DNS server and use `nslookup` to determine whether the query reaches and receives a valid response**
Explanation: The evidence narrows the issue toward DNS; inspecting the resolver configuration and query result is a targeted next step.

**10. (Difficult) — B. Test the required service from an authorized client and record the actual result, alongside supporting network checks**
Explanation: The actual required service should be tested; lower-layer checks help explain failures but cannot substitute for that test.

### Instructor-only selection notes

- Final question 1 (original draft question 2): Retained for the router's central role in forwarding traffic between IP networks.
- Final question 2 (original draft question 3): Retained for a core network service that supplies client IP configuration automatically.
- Final question 3 (original draft question 4): Retained for a practical Windows command used to inspect network adapter configuration.
- Final question 4 (original draft question 5): Retained for physical-layer cable testing and what a tester can reveal.
- Final question 5 (original draft question 7): Retained to assess topology and how a central-switch star helps isolate a single endpoint-link fault.
- Final question 6 (original draft question 9): Retained for safe static-address planning and avoidance of address conflicts.
- Final question 7 (original draft question 12): Retained for diagnosing hostname resolution when IP reachability works.
- Final question 8 (original draft question 14): Retained for choosing modern Wi-Fi security with an appropriate compatibility fallback.
- Final question 9 (original draft question 17): Retained for evidence-based, targeted diagnosis of a likely DNS failure.
- Final question 10 (original draft question 19): Retained because a required application service must be tested directly, not inferred from lower-layer checks.
