# COC 2 — Lesson 2: Network Installation and Configuration

## Video Lessons

1. **[How to Crimp an Ethernet Cable Without Tools: Twisted Pair, RJ-45, T568B, and a Crimper — Club DNS](https://www.youtube.com/watch?v=mXIcovNBtTk)**  
   Demonstrates twisted-pair cable construction, T568A/T568B pinouts, connector preparation, crimping, and cable testing. The video also shows a tool-less method; for CSS laboratory practice, use the correct crimping tool and approved connectors.

2. **[CSS NC II COC 2 — Set Up Computer Network](https://www.youtube.com/watch?v=fcFmsmXaoW4)**  
   A local CSS NC II practical walkthrough covering workgroup setup, dynamic/static IPv4 configuration, router access, Wi-Fi settings, file sharing, and ping verification. Instructor must correct the example's weak Wi-Fi password: never teach or reuse `123456789`; use a unique strong passphrase and current supported security such as WPA3 or WPA2-AES.

3. **[WiFi (Wireless) Password Security — WEP, WPA, WPA2, WPA3, WPS Explained — PowerCert Animated Videos](https://www.youtube.com/watch?v=WZaIfyvERcA)**  
   Explains wireless security generations and related options. Use it to compare standards; emphasize WPA3 where supported, or WPA2-Personal with AES when WPA3 is unavailable. Avoid WEP, TKIP, and open networks.

### Instructor notes
- Use the same T568A or T568B standard at both ends for a straight-through cable. Traditional crossover wiring uses different standards at opposite ends; Auto-MDIX on many modern devices often makes crossover cables unnecessary.
- Router menus vary by manufacturer. Demonstrate using a lab router and reset it after practice.
- Do not publish real router-admin credentials, Wi-Fi passwords, or student network details in submitted work.
