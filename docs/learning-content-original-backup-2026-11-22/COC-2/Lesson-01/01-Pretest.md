# COC 2 — Lesson 1: Network Concepts and Planning

## Pretest

Learner’s Module | Pretest • Lessons • Visual Guides • Activity • Post-test

Module overview

This module introduces the knowledge and practical skills needed to install network cables, configure computer network settings, configure a router or wireless access point, and inspect and test a working network. It is designed as instructional content that can later be divided into screens, lessons, activities, and assessments in a front-end learning management system.

Learning outcomes

Plan a basic LAN/SOHO network installation and identify suitable materials, tools, and safety practices.

Prepare and install Ethernet cabling, including terminating an RJ-45 plug using the T568B wiring standard.

Configure basic IPv4 settings and verify communication between devices.

Configure basic router and Wi-Fi settings using secure practices.

Inspect, test, troubleshoot, and document a small computer network.

How to use this module

Complete the pretest before studying. Read each lesson and study its diagrams and examples. Perform the activity only with instructor approval and authorized equipment. Finish with the post-test. Do not change a live school or business network without permission.
