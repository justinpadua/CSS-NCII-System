# COC 2 — Lesson 1: Network Concepts and Planning

## Video Lessons

1. **[Network Types: LAN, WAN, PAN, CAN, MAN, SAN, WLAN — PowerCert Animated Videos](https://www.youtube.com/watch?v=4_zSIXb7tLQ)**  
   Explains network categories by coverage and use. Focus on LAN, WAN, and WLAN, then compare the other types introduced in the lesson.

2. **[Network Topologies (Star, Bus, Ring, Mesh, Ad hoc, Infrastructure, & Wireless Mesh Topology) — PowerCert Animated Videos](https://www.youtube.com/watch?v=zbqrNg4C98U)**  
   Explains common physical/logical layout concepts, including star, bus, ring, and mesh topologies.

3. **[Computer Networking Tutorial — What is a Computer Network? — TheNewBoston](https://www.youtube.com/watch?v=ueVnSz_IXEs)**  
   Beginner introduction to computer networks. The related tutorial series also contains separate videos on network types, network parts, servers, clients/hosts, NICs, and protocols.

4. **[Hub, Switch & Router Explained — What's the difference? — PowerCert Animated Videos](https://www.youtube.com/results?search_query=PowerCert+Hub+Switch+Router+Explained+Whats+the+difference)**  
   YouTube search link for the named PowerCert lesson. Select the matching PowerCert video when viewing; the search link is used because a direct video URL was not independently confirmed during this review.

### Viewing guide
Ask students to draw a small home or school LAN, label its end devices and network devices, and explain why the selected topology and network type fit the scenario. Use the discussion for IP addressing and planning; the videos above do not replace subnetting or address-planning practice.
