4.1 Inspection checklist

Confirm that equipment is powered, ventilated, labeled, and placed securely.

Inspect cable routes, connectors, strain relief, raceways, and trip hazards.

Check link/activity indicators on NICs, switches, and routers.

Verify IP address, subnet mask, gateway, and DNS settings on representative clients.

Test communication between intended devices and test internet access only if it is part of the network requirement.

Check wireless coverage in the required areas and verify that unauthorized/open access is not enabled.

Record test results, device names, IP addresses, cable labels, configuration changes, and unresolved issues.

4.2 A simple test sequence

A failed ping does not always prove a network is broken: a host firewall may block ICMP. Use more than one test and interpret results in context.
