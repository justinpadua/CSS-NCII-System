# COC 1 — Lesson 6: Computer Testing and Documentation

## Posttest

LESSON 6 – POST-TEST (10 ITEMS)

Directions: Read each question carefully. Choose the letter of the best answer.

1. A stress test evaluates a computer's performance and stability under what condition?

A. Heavy workload

B. No power

C. No components installed

D. Only during shutdown

2. Which test type is intended to load the graphics card?

A. GPU test

B. Audio test

C. Keyboard test

D. Printer test

3. Why monitor temperatures during a stress test?

A. To detect overheating and thermal throttling

B. To change the desktop theme

C. To increase disk space

D. To reset the BIOS password

4. Which software is commonly used for CPU, GPU, memory, and power testing?

A. OCCT

B. Paint

C. WordPad

D. File Explorer

5. A system shuts down during a test. What should the technician do first?

A. Record the event, stop testing, and inspect likely causes safely

B. Immediately repeat the test without checking

C. Disable all fans

D. Delete the OS

6. What does thermal throttling mean?

A. The component reduces performance to control temperature or power

B. The monitor changes resolution

C. The SSD becomes a USB drive

D. The keyboard disconnects

7. Which entry belongs in a test log?

A. Start/end time and observed maximum temperature

B. Technician's favorite color

C. Desktop wallpaper name

D. Number of browser tabs from last week

8. Why run tests one at a time when diagnosing a suspected fault?

A. To isolate which component or workload causes the issue

B. To make the test look longer

C. To use more electricity

D. To avoid recording results

9. What is a reasonable action after a failed GPU test?

A. Check temperatures, power connections, driver status, and repeat only after correction

B. Ignore the error

C. Remove the CPU

D. Format every drive

10. What should the final report state?

A. Test configuration, measured results, errors, conclusion, and recommendations

B. Only pass or fail with no details

C. Only the PC brand

D. Only the date
