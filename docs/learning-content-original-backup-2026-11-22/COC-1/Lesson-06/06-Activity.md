# COC 1 — Lesson 6: Computer Testing and Documentation

## Activity

LESSON 6 – ACTIVITY: PUSH IT, MEASURE IT

Practice stress testing and reporting.

How to use: click each gray field in Microsoft Word to pick an answer from the drop-down list, tick a box, or type your response.

Part A – Order the Stress Test

Number the steps from 1 to 7 in the correct order.

Part B – Match the Term

Choose the term that fits each description.  Word bank: Artifacts • Fault isolation • Idle temperature • Peak temperature • Test log • Thermal throttling

Part C – What Do You Do?

Choose the best response to each observation.  Word bank: Ignore the result • Report the system as stable • Reseat or replace the RAM, then retest • Stop the test • Suspect a graphics problem

Part D – Write the Conclusion

Test data: CPU idle 40°C, peak 98°C, performance dropped after 5 minutes, no crashes.

Write a short conclusion and one recommendation.

Instructor Answer Key

Part A: "Check the assembly, cooling, and connections" = 1; "Start one test (for example, CPU) while monitoring" = 3; "Prepare the test report with recommendations" = 7; "Record peak temperatures and errors in the log" = 6; "Stop the test when it is finished or limits are exceeded" = 5; "Record the baseline specifications and idle temperatures" = 2; "Monitor temperatures and errors continuously" = 4

Part B: 1. Thermal throttling, 2. Artifacts, 3. Idle temperature, 4. Peak temperature, 5. Fault isolation, 6. Test log

Part C: 1. Stop the test, 2. Suspect a graphics problem, 3. Reseat or replace the RAM, then retest, 4. Report the system as stable

Part D: Answers vary. Sample: CPU overheated and throttled under load; improve cooling (clean fans, reapply thermal paste, or upgrade the cooler) and retest.
