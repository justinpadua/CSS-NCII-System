# COC 1 — Lesson 3: Disassembly and Assembly of Computer Hardware

## Definition of Terms

LESSON 3 – DEFINITION OF TERMS

Study these key terms before starting the lesson.

System Unit – The main enclosure that contains the computer's internal components.

Disassembly – The careful step-by-step removal of the parts of a computer.

Assembly – The step-by-step installation of computer parts to build a working system.

CPU Socket – The motherboard connector where the CPU is installed.

RAM Slot – The motherboard slot where memory modules are installed.

PCIe Slot – A motherboard slot used for expansion cards such as a graphics card.

SATA Connector – A connector used to attach SATA storage devices to the motherboard.

M.2 NVMe SSD – A fast solid-state drive that uses the NVMe protocol.

Expansion Card – A circuit board, such as a GPU, that adds features to a computer.

Heat Sink – A metal part that draws heat away from the CPU or other components.

Thermal Paste – A compound applied between the CPU and cooler to improve heat transfer.

Volatile Memory – Memory whose contents are lost when power is turned off, such as RAM.

CMOS Battery – A small battery that maintains certain firmware settings and the real-time clock when the PC is disconnected from power.

Standoffs – Spacers that hold the motherboard above the metal case.

CPU_FAN Header – The motherboard connector for the CPU fan cable.

24-Pin Power Connector – The main power cable that supplies power to the motherboard.

Front-Panel Connectors – Cables for the power switch, reset switch, LEDs, front USB, and audio.

Cable Management – Neatly routing and securing cables to improve airflow and prevent damage.

Power-On Self-Test (POST) – A startup check that tests basic hardware before the operating system loads.

Troubleshooting – The systematic process of identifying, diagnosing, and correcting computer problems.

3.1 Internal Parts of the System Unit

The system unit is the main enclosure that contains the computer's internal components.

Motherboard

The motherboard is the main circuit board of the computer.

It connects the CPU, RAM, storage devices, GPU, and other components.

It provides communication pathways between hardware components.

Important parts include CPU socket, RAM slots, PCIe slots, SATA connectors, and power connectors.

B. Central Processing Unit (CPU)

The CPU processes instructions and performs calculations.

It is often called the brain of the computer.

It works with RAM and other components.

It requires a cooling system to prevent overheating.

Random Access Memory (RAM)

RAM temporarily stores data and instructions being used.

It allows the computer to access active data quickly.

RAM is volatile, meaning its contents are lost when power is turned off.

Common types include DDR3, DDR4, and DDR5.

D. Storage Devices

HDD – stores data using magnetic disks.

SATA SSD – stores data using flash memory.

M.2 NVMe SSD – provides fast storage through the NVMe protocol.

Storage devices retain files even when the computer is powered off.

E. Power Supply Unit (PSU)

Supplies electrical power to the computer.

Converts AC electricity into DC power.

Provides power through connectors such as 24-pin motherboard, CPU power, SATA power, and PCIe power.

A defective PSU may cause startup failure or unexpected shutdowns.

F. Graphics Processing Unit (GPU)

Processes graphics and visual information.

Helps run games, video editing applications, and 3D programs.

May be integrated into the CPU or installed as a separate graphics card.

G. Cooling System

Removes heat from the CPU and other components.

Includes fans, heat sinks, and sometimes liquid cooling.

Prevents overheating and performance reduction.

H. Computer Case

Holds and protects the internal components.

Provides mounting locations for the motherboard, PSU, drives, and fans.

Helps manage airflow.

CMOS Battery

Maintains certain firmware settings and the real-time clock when the PC is disconnected from power.

A weak battery may cause clock resets or settings loss on some systems.

3.2 How to Disassemble a System Unit PC (Step-by-Step Procedure)

Tools Needed

Phillips screwdriver

Flathead screwdriver (if required)

Antistatic wrist strap

ESD mat

Small containers for screws

Camera or smartphone for recording cable positions

Soft brush or compressed air for cleaning

Procedure

Prepare the Work Area

Use a clean, dry, well-lit workbench.

Place an ESD mat on the work surface.

Organize tools and screw containers.

Shut Down the Computer

Save all work.

Shut down the operating system.

Turn off the PSU switch if present.

Disconnect All Cables

Unplug the power cable.

Disconnect monitor, keyboard, mouse, USB devices, and network cables.

Wait for the system to fully discharge.

Open the Computer Case

Remove the side-panel screws.

Slide or lift the panel according to the case design.

Place the panel in a safe location.

Use ESD Protection

Wear a properly grounded antistatic wrist strap.

Handle components by their edges.

Avoid touching contacts and exposed circuitry.

Disconnect Internal Cables

Disconnect motherboard power cables.

Disconnect SATA data and power cables.

Disconnect front-panel cables and fan cables as needed.

Take pictures before removing connections.

Remove Expansion Cards

Unscrew the GPU or other expansion cards.

Release the PCIe slot latch carefully.

Lift the card straight out.

Remove RAM Modules

Release the RAM slot clips.

Hold the module by its edges.

Lift it carefully from the slot.

Remove Storage Devices

Unscrew the HDD or SSD mounting screws.

Disconnect cables.

Place the storage device in an ESD-safe container.

Remove the CPU Cooling System

Follow the cooler manufacturer's procedure.

Disconnect the fan cable.

Loosen mounting screws gradually and evenly.

Carefully remove the cooler.

Do not pull forcefully or twist in a way that may damage the CPU socket.

Remove the CPU (If Necessary)

Release the socket locking mechanism.

Lift the CPU by its edges.

Avoid touching pins or contact pads.

Store in a protective CPU container.

Remove the PSU

Disconnect remaining PSU cables.

Remove the mounting screws.

Carefully slide out the PSU.

Remove the Motherboard

Remove the motherboard mounting screws.

Lift the motherboard carefully.

Place it on an ESD-safe surface.

Organize the Components

Label the parts.

Store screws separately.

Inspect components for visible damage.

3.3 How to Assemble a System Unit PC (Step-by-Step Procedure)

Tools Needed

Phillips screwdriver

ESD wrist strap

ESD mat

Thermal paste, when needed

Cable ties or cable management straps

Component manuals

Procedure

Prepare the Work Area

Clean the workbench.

Use ESD protection.

Check all parts for compatibility.

Install the CPU

Open the CPU socket.

Align the CPU using the orientation marker.

Place it gently into the socket.

Lock the socket according to the motherboard instructions.

Install RAM

Check the recommended RAM slots in the motherboard manual.

Align the notch.

Press evenly until the retaining clips lock.

Install the CPU Cooler

Apply thermal paste if the cooler does not have pre-applied paste.

Mount the cooler according to its manual.

Connect the CPU fan to the CPU_FAN header.

Prepare the Computer Case

Install motherboard standoffs in the correct positions.

Install the I/O shield if the board requires a separate one.

Ensure no extra standoffs are touching the motherboard.

Install the Motherboard

Align the motherboard with the case.

Place it onto the standoffs.

Secure it with screws without overtightening.

Install the PSU

Position the PSU according to the case design.

Secure it using screws.

Route the power cables neatly.

Install Storage Devices

Mount the SSD or HDD.

Connect SATA data and power cables if required.

M.2 drives should be installed in the correct slot and secured with the proper screw.

Install the GPU

Insert the GPU into the correct PCIe slot.

Secure it to the case.

Connect required GPU power cables.

Connect Power Cables

Connect the 24-pin motherboard power cable.

Connect the CPU power cable.

Connect SATA power to appropriate devices.

Follow the PSU manufacturer's cable compatibility guidance.

Connect Front-Panel Cables

Connect power switch, reset switch, LEDs, front USB, and audio.

Use the motherboard manual for pin locations.

Check Cooling and Cable Management

Ensure fans are connected.

Keep cables away from fan blades.

Check that all components are firmly seated.

Perform Initial Testing

Connect monitor, keyboard, and power cable.

Turn on the computer.

Check for POST and BIOS/UEFI access.

Confirm that CPU, RAM, and storage are detected.

Close the Case

After successful testing, install the side panel.

Reconnect peripherals and prepare for software installation.

3.4 How to Troubleshoot a Malfunctioning Computer System

Troubleshooting is the systematic process of identifying and correcting computer problems.

A. Common Computer Problems and Solutions

B. Troubleshooting Procedure

Identify the problem.

Ask the user about symptoms and recent changes.

Check power and external connections.

Observe error messages or diagnostic indicators.

Identify possible causes.

Test one possible cause at a time.

Apply the appropriate solution.

Verify that the computer works properly.

Document the repair and findings.

Example

Problem: The computer powers on, but there is no display.

Check whether the monitor is powered on.

Check HDMI or DisplayPort connections.

Confirm the correct monitor input.

Check whether the display cable is connected to the appropriate graphics output.

Inspect RAM seating and diagnostic indicators if needed.

Test with a known-good monitor or cable.

Record the result.
