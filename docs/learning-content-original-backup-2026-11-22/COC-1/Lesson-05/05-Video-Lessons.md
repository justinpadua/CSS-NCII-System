# COC 1 — Lesson 5: Installation of System and Application Software

## Video Lessons

1. **[New PC Setup: Windows Install, BIOS and Drivers — ExplainingComputers](https://www.youtube.com/watch?v=pJFvqaIa-38)**  
   Walks through BIOS settings, Windows installation, and motherboard and graphics drivers. Use the relevant chapters for firmware setup and driver installation.

2. **[How to Install Windows 11 from a USB Flash Drive in 2026 | Clean Installation Step-by-Step](https://www.youtube.com/watch?v=cE0eEgtZWFg)**  
   Demonstrates booting from installation media, starting Windows Setup, selecting a partition, and completing installation. The narration is in Russian; use subtitles if available. Treat the partition-selection section as instructor-led because choosing or deleting the wrong partition can destroy data.

3. **[Microsoft — Download Windows 11 / Create installation media](https://www.microsoft.com/software-download/windows11)**  
   Official reference for obtaining Windows installation media. Review system requirements and licensing before installation.

### Instructor notes
- BIOS/UEFI menus differ by manufacturer and model; learners should use the actual computer's manual.
- Back up data and confirm the target disk before formatting, deleting, or creating partitions.
- Download drivers from the PC or component manufacturer's official support page. Avoid third-party driver-download sites.
- Demonstrate installation only on an authorized lab computer or virtual machine.
