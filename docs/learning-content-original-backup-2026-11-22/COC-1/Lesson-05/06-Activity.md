# COC 1 — Lesson 5: Installation of System and Application Software

## Activity

LESSON 5 – ACTIVITY: INSTALL AND CONFIGURE

Practice installing and configuring an operating system.

How to use: click each gray field in Microsoft Word to pick an answer from the drop-down list, tick a box, or type your response.

Part A – Order the Installation

Number the steps from 1 to 7 in the correct order.

Part B – Match the Term

Choose the term that fits each description.  Word bank: BIOS/UEFI • Backup • Device Manager • Disk Management • Driver • Partition

Part C – After the Installation

Tick every task that belongs after installing the operating system.

Install the correct device drivers

Check network, audio, and display

Install needed applications

Document the installation

Delete the EFI or recovery partition

Skip the backup to save time

Part D – Troubleshoot It

A newly built PC will not boot from the USB installer.

List two things you would check or change.

Instructor Answer Key

Part A: "Select the target drive and install the operating system" = 4; "Boot from the installation media" = 3; "Get authorization and back up important data" = 1; "Install applications and document the work" = 7; "Install drivers and updates" = 6; "Complete the initial setup and create the user account" = 5; "Set the USB as the first boot device in BIOS/UEFI" = 2

Part B: 1. BIOS/UEFI, 2. Partition, 3. Disk Management, 4. Device Manager, 5. Driver, 6. Backup

Part C: Check: Install the correct device drivers; Check network, audio, and display; Install needed applications; Document the installation

Part D: Answers vary. Sample: set the USB as first boot device in BIOS/UEFI; check that the USB was created correctly (GPT/MBR to match UEFI/BIOS).
