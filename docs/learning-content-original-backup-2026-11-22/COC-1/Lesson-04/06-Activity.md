# COC 1 — Lesson 4: Creation of Portable Bootable Devices

## Activity

LESSON 4 – ACTIVITY: BOOT IT UP

Practice creating and testing bootable media.

How to use: click each gray field in Microsoft Word to pick an answer from the drop-down list, tick a box, or type your response.

Part A – Order the Rufus Procedure

Number the steps from 1 to 7 in the correct order.

Part B – Match the Command

Choose the command or tool for each purpose.  Word bank: assign • diskpart • list disk • list volume • oscdimg • select disk

Part C – True or False

Choose True or False for each statement.

Part D – Customer Checklist

Before making a bootable USB for a customer:

Write three things you must check or tell the customer first.

Instructor Answer Key

Part A: "Download a valid ISO image from the official source" = 1; "Click START and confirm the erase warning" = 6; "Safely eject the USB and test it using the boot menu" = 7; "Choose the partition scheme for the target computer" = 5; "Plug in the USB drive (8 GB or more) and back up its files" = 2; "Open Rufus and select the USB device" = 3; "Click SELECT and choose the ISO image" = 4

Part B: 1. diskpart, 2. list disk, 3. select disk, 4. list volume, 5. assign, 6. oscdimg

Part C: 1. True; 2. False; 3. True; 4. True; 5. False

Part D: Answers vary. Sample: back up the USB files; confirm the ISO is from an official source; choose GPT or MBR to match the target computer.
