# COC 1 — Lesson 4: Creation of Portable Bootable Devices

## Posttest

LESSON 4 – POST-TEST (10 ITEMS)

Directions: Read each question carefully. Choose the letter of the best answer.

1. Which of the following is a third-party application that can create ISO images?

A. Notepad

B. Windows Calculator

C. PowerISO

D. Task Manager

A. Unplug the computer

B. Verify that the correct USB device is selected and important files are backed up

C. Delete the ISO image

3. Which command-line utility from the Windows ADK can create an ISO image?

A. oscdimg

B. list disk

C. assign

D. diskpart

4. Which statement about creating ISO images with Windows commands is correct?

A. Windows has a built-in command that creates an ISO from any folder

B. Windows commands can only format printers

C. ISO images cannot be created from folders

B. Displays volumes

C. Deletes volumes

D. Formats the USB drive

6. Which diskpart command assigns a drive letter?

A. format

B. select disk

C. assign

D. list disk

7. Which of the following is an example of a bootable device?

B. Computer mouse

C. Printer cartridge

D. Monitor stand

8. Why should a legitimate ISO image from an official source be used?

A. To make the USB heavier

B. To increase monitor brightness

C. To make the file name longer

D. To reduce the risk of tampered or unsafe installation files

9. What should be done after Rufus finishes creating the bootable USB?

A. Delete the USB contents

B. Leave it plugged in forever

C. Safely eject the USB and test it using the boot menu

D. Format it again immediately

B. For every modern UEFI system only
