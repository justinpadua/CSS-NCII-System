### Important distinction
An ISO is a disc-image file. Creating or obtaining an ISO is a separate step from writing that ISO to a USB drive. Rufus writes an existing ISO to the selected USB drive; it does not author a custom ISO from a folder. Always back up the USB first because its contents will be erased.
