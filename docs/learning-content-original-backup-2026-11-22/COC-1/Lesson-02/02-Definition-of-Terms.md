# COC 1 — Lesson 2: Elements of Computer Systems

## Definition of Terms

LESSON 2 – DEFINITION OF TERMS

Study these key terms before starting the lesson.

Computer System – A combination of hardware, software, peopleware, and dataware that work together to process data and produce useful information.

Hardware – The physical components of a computer that can be touched.

Software – Programs and instructions that operate a computer or perform tasks for the user.

Peopleware – The people who operate, manage, maintain, or develop computer systems.

Dataware – The data and information stored, processed, and managed by a computer system.

Motherboard – The main circuit board that connects the computer's components.

Central Processing Unit (CPU) – The component that processes instructions and performs calculations.

Random Access Memory (RAM) – Temporary memory that holds the data and programs currently in use.

Storage Device – Hardware that retains files even when the computer is powered off.

Power Supply Unit (PSU) – The component that converts electrical power into usable power for the computer.

Graphics Processing Unit (GPU) – The component that processes graphics and visual information.

Cooling System – Fans, heat sinks, or liquid cooling used to remove heat from components.

Operating System – System software that manages hardware and software resources.

Device Driver – Software that lets the operating system communicate with a hardware device.

Utility Software – System software that maintains and protects the computer.

Firmware – Low-level software stored in hardware, such as BIOS and UEFI.

System Software – Software that supports the operation of the computer and provides a platform for applications.

Application Software – Software that helps users perform specific tasks and depends on system software to run.

2.1 Computer Parts, Software, Peopleware, and Dataware

A computer system is composed of different elements that work together to process data and produce useful information.

Hardware

Examples and functions:

CPU – processes instructions.

Motherboard – connects components.

RAM – temporarily stores active data.

HDD/SSD – stores files and programs.

Monitor – displays information.

Keyboard – enters data.

Mouse – controls the pointer.

Printer – produces printed output.

Software

Software consists of computer programs and instructions.
