C. Peopleware

Peopleware refers to the people who operate, manage, maintain, or develop computer systems.

Examples:

Computer technician – repairs and maintains computers.

Programmer – develops software.

System administrator – manages computer systems.

End-user – uses the computer for daily tasks.

IT manager – supervises IT operations.

Functions of peopleware:

Operates computer systems.

Provides instructions to computers.

Maintains hardware and software.

Manages and protects information.

Solves computer-related problems.

Dataware

Dataware refers to the data and information stored, processed, and managed by a computer system.

Examples:

Student records

Customer information

Employee records

Digital documents

Images and videos

Inventory records

Database files

Functions of dataware:

Stores important information.

Provides data for processing.

Supports decision-making.

Allows retrieval and organization of information.

Helps maintain business and academic records.

E. How the Elements Work Together

Example: A student prepares a report using a computer.

Peopleware: The student operates the computer.

Hardware: The keyboard, CPU, monitor, and SSD are used.

Software: Microsoft Word is used to prepare the report.

Dataware: The report's text, images, and saved document are the data.

2.2 Identify and Differentiate System and Application Software

A. System Software

System software manages the computer's hardware and provides a platform for application software.

Types of system software:

- Operating System

Manages hardware and software.

Provides a user interface.

Examples: Windows, Linux, macOS.

- Device Drivers

Allow the operating system to communicate with hardware.

Examples: printer driver, graphics driver, audio driver.

- Utility Software

Performs maintenance and protection tasks.

Examples: antivirus, disk cleanup tools, backup utilities.

- Firmware

Provides basic instructions stored in hardware.

Examples: BIOS and UEFI firmware.

B. Application Software

Application software helps users perform specific tasks.

C. Comparison of System and Application Software

D. Practical Example

When a user opens Microsoft Word:

The operating system manages the computer resources.

The CPU executes instructions.

RAM holds the active application and data.

Microsoft Word allows the user to prepare a document.

The SSD stores the saved file.

This demonstrates how system software and application software work together.
