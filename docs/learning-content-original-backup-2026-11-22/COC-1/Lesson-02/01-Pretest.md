# COC 1 — Lesson 2: Elements of Computer Systems

## Pretest

LESSON 2 – PRE-TEST (10 ITEMS)

Directions: Read each question carefully. Choose the letter of the best answer.

1. Which four elements make up a computer system?

A. Keyboard, mouse, monitor, and printer

B. Hardware, software, peopleware, and dataware

C. CPU, RAM, HDD, and PSU

D. Input, output, storage, and cables

2. What does dataware refer to?

A. The physical parts of a computer

B. The programs installed in a computer

C. The cables of a computer

D. The data and information processed and stored by a computer

3. Which component is the main circuit board of the computer?

A. Motherboard

B. RAM

C. PSU

D. Monitor

4. Which component helps remove heat from the CPU?

A. Monitor

B. Keyboard

C. Heat sink and fan

D. Mouse

5. Which component supplies electrical power to the computer?

A. RAM

B. PSU

C. GPU

D. SSD

6. Which of the following is an application software?

A. BIOS

B. Windows 11

C. Device driver

D. Google Chrome

7. Which of the following is system software?

A. Operating system

B. Microsoft Word

C. VLC Media Player

D. Adobe Photoshop

8. Which of the following is an example of peopleware?

A. A saved report

B. A monitor

C. A computer technician

D. A RAM module

9. Which component processes graphics and visual information?

A. PSU

B. RAM

C. HDD

D. GPU

10. Which component temporarily holds the programs and data being used by the computer?

A. RAM

B. SSD

C. Power supply

D. Webcam

Answer Key: 1. B   2. D   3. A   4. C   5. B   6. D   7. A   8. C   9. D   10. A
