2.1 Computer Parts, Software, Peopleware, and Dataware
A computer system is composed of different elements that work together to process data and produce useful information.

1.	Hardware

Examples and functions:
1.	CPU – processes instructions.
2.	Motherboard – connects components.
3.	RAM – temporarily stores active data.
4.	HDD/SSD – stores files and programs.
5.	Monitor – displays information.
6.	Keyboard – enters data.
7.	Mouse – controls the pointer.
8.	Printer – produces printed output.





1.	Software
	












Software consists of computer programs and instructions.
Examples:
1.	Windows – operating system.
1.	Linux – operating system.
2.	Microsoft Word – word-processing application.
3.	Microsoft Excel – spreadsheet application.
4.	Google Chrome – web browser.
5.	Antivirus – security software.

C. Peopleware
Peopleware refers to the people who operate, manage, maintain, or develop computer systems.
Examples:
1.	Computer technician – repairs and maintains computers.
2.	Programmer – develops software.
3.	System administrator – manages computer systems.
4.	End-user – uses the computer for daily tasks.
5.	IT manager – supervises IT operations.
Functions of peopleware:
1.	Operates computer systems.
2.	Provides instructions to computers.
3.	Maintains hardware and software.
4.	Manages and protects information.
5.	Solves computer-related problems.

1.	Dataware
Dataware refers to the data and information stored, processed, and managed by a computer system.
Examples:
1.	Student records
2.	Customer information
3.	Employee records
4.	Digital documents
5.	Images and videos
6.	Inventory records
7.	Database files
Functions of dataware:
1.	Stores important information.
2.	Provides data for processing.
3.	Supports decision-making.
4.	Allows retrieval and organization of information.
5.	Helps maintain business and academic records.
E. How the Elements Work Together
Example: A student prepares a report using a computer.
1.	Peopleware: The student operates the computer.
2.	Hardware: The keyboard, CPU, monitor, and SSD are used.
3.	Software: Microsoft Word is used to prepare the report.
4.	Dataware: The report's text, images, and saved document are the data.

 


2.2 Identify and Differentiate System and Application Software
A. System Software
System software manages the computer's hardware and provides a platform for application software.
Types of system software:
 
- Operating System
1.	Manages hardware and software.
2.	Provides a user interface.
3.	Examples: Windows, Linux, macOS.
- Device Drivers
1.	Allow the operating system to communicate with hardware.
2.	Examples: printer driver, graphics driver, audio driver.
- Utility Software
1.	Performs maintenance and protection tasks.
2.	Examples: antivirus, disk cleanup tools, backup utilities.
- Firmware
1.	Provides basic instructions stored in hardware.
2.	Examples: BIOS and UEFI firmware.



B. Application Software
Application software helps users perform specific tasks.
Application	Function
Microsoft Word	Creates documents
Microsoft Excel	Performs calculations and organizes data
Microsoft PowerPoint	Creates presentations
Google Chrome	Browses the internet
Adobe Photoshop	Edits images
VLC Media Player	Plays multimedia files
AutoCAD	Creates technical drawings
Zoom	Supports online meetings
C. Comparison of System and Application Software
System Software	Application Software
Manages computer resources	Performs specific user tasks
Supports the operation of the computer	Depends on system software to run
Often starts during booting	Usually opened by the user
Examples: Windows, Linux, drivers	Examples: Word, Excel, Chrome
D. Practical Example
When a user opens Microsoft Word:
1.	The operating system manages the computer resources.
2.	The CPU executes instructions.
3.	RAM holds the active application and data.
4.	Microsoft Word allows the user to prepare a document.
5.	The SSD stores the saved file.
