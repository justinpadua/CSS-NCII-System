# COC 1 — Lesson 2: Elements of Computer Systems

## Posttest

LESSON 2 – POST-TEST (10 ITEMS)

Directions: Read each question carefully. Choose the letter of the best answer.

1. Peopleware refers to which of the following?

A. Only the computer hardware

B. Only the installed programs

C. The people who operate, manage, maintain, or develop computer systems

D. The data saved in a computer

2. Dataware refers to which of the following?

A. The data and information stored, processed, and managed by a computer system

B. The people using the computer

C. The tools used for repair

D. The electrical cables

3. What is the main role of system software?

A. Edits photos only

B. Plays music only

C. Prints documents only

D. Manages the hardware and provides a platform for application software

4. Which type of software depends on system software to run?

A. Firmware

B. Application software

C. BIOS

D. Operating system

5. Which of the following is an example of firmware?

A. BIOS or UEFI

B. Microsoft Excel

C. Google Chrome

D. VLC Media Player

6. Which statement best describes a device driver?

A. A tool for tightening screws

B. A type of storage device

C. Software that allows the operating system to communicate with a hardware device

D. A cable for connecting a monitor

7. A student prepares a school report in a word processor. Which item is the dataware?

A. The monitor

B. The report's text, images, and saved document

C. The student

D. The operating system

8. In the same scenario, which item is the application software?

A. The CPU

B. The SSD

C. The keyboard

D. Microsoft Word

9. Which pair contains only examples of system software?

A. Windows and Linux

B. Microsoft Word and Excel

C. Google Chrome and VLC Media Player

D. Adobe Photoshop and Excel

10. Which statement correctly compares system software and application software?

A. Application software supports the operation of the computer, while system software edits documents

B. They perform exactly the same tasks

C. System software supports computer operation, while application software helps users perform specific tasks

D. Neither one needs a computer to run

Answer Key: 1. C   2. A   3. D   4. B   5. A   6. C   7. B   8. D   9. A   10. C
