# COC 1 — Lesson 2: Elements of Computer Systems

## Video Lessons

1. **[Components of a Computer Systems — John Carlo Camba](https://www.youtube.com/watch?v=peas75zRolo)**  
   Directly discusses hardware, software, dataware, and peopleware. Use this as the main video for the four elements of a computer system.

2. **[System Software vs Application Software | Explained with Examples — Digital Dynamo Lab](https://www.youtube.com/watch?v=hLrMEfmpVr8)**  
   Explains the difference between system software and application software and gives examples such as operating systems, device drivers, word processors, browsers, and media players.

3. **[Hardware and Software — Khan Academy / Code.org](https://www.khanacademy.org/computing/computer-science/how-computers-work2/v/khan-academy-and-codeorg-hardware-and-software)**  
   Explains how physical hardware and software work together. This is a supplementary lesson rather than a replacement for the four-element discussion.

### Viewing guide
- While watching Video 1, list one example each of hardware, software, peopleware, and dataware.
- While watching Video 2, classify each software example as system software or application software and explain why.
