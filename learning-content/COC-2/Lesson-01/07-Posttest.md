# COC 2 — LESSON 1: Post-test

## Lesson 1 — Post-Test (10 Items)

**Directions:** Read each question carefully. Choose the letter of the best answer. Each item is worth 1 point.

1. **Which device gives a LAN more Ethernet ports?**
   - A. Router only
   - B. Printer
   - C. Switch
   - D. Modem

2. **What does a modem/ONT do?**
   - A. Supplies power
   - B. Prints documents
   - C. Crimps plugs
   - D. Terminates the service-provider connection

3. **In T568B, what is the color of pin 1?**
   - A. Blue
   - B. White/Orange
   - C. Green
   - D. Brown

4. **In T568B, what is the color of pin 4?**
   - A. Blue
   - B. Green
   - C. Orange
   - D. Brown

5. **Which tool terminates conductors on a keystone jack?**
   - A. Crimping tool
   - B. Cable cutter only
   - C. Punch-down tool
   - D. Tape measure

6. **For a straight-through cable, how are both ends wired?**
   - A. Using the same wiring standard
   - B. Using different standards
   - C. Without any standard
   - D. Using only one wire

7. **What should be done after crimping the plug?**
   - A. Use it immediately
   - B. Paint it
   - C. Throw it away
   - D. Test the cable with a cable tester

8. **What can a basic continuity tester NOT do?**
   - A. Identify many wiring faults
   - B. Certify performance at a particular Ethernet category or data rate
   - C. Detect opens
   - D. Show pin mapping

9. **Which describes safe cable routing?**
   - A. Run cable where it may be crushed
   - B. Run cable through wet areas
   - C. Bend the cable sharply
   - D. Avoid crushing or sharp bends and keep separation from power wiring

10. **Why should RJ-45 plugs be compatible with the cable?**
    - A. So the plug fits the cable type (Cat5e or Cat6) properly
    - B. So the cable looks nicer
    - C. So the cable becomes wireless
    - D. So the router resets
