# COC 2 — Lesson 3: Network Testing and Documentation

## Definition of Terms

- **Link/activity indicator:** A light or status signal that may show a physical or wireless link and traffic activity.
- **Wire map:** The pin-to-pin conductor mapping reported by a cable tester.
- **ICMP:** Internet Control Message Protocol, used for network messages including echo request/reply tests.
- **Ping:** A command that sends ICMP echo requests and reports replies, timing, or loss; it does not test every application service.
- **Loopback address:** An address used by a device to test its own TCP/IP stack; 127.0.0.1 is the IPv4 loopback address.
- **ipconfig:** A Windows command that displays or manages local IP configuration; ipconfig /all shows detailed adapter settings.
- **nslookup:** A command-line tool used to query DNS name resolution.
- **Retest:** Repeating the relevant check after a corrective action to determine whether the observed issue changed.
- **Test record:** A report of scope, device identifiers, commands/tools, results, corrective actions, retest results, and unresolved issues.
