# COC 2 — Lesson 3: Network Testing and Documentation

## Examples

### Troubleshoot a name-resolution problem

A workstation has a valid address and can receive a reply when it pings the approved gateway. A lookup for a required domain name fails. The technician records the exact commands and results, checks the configured DNS server and its reachability, and compares the client's settings with an authorized working device. The technician does not conclude that internet access is fully working from a gateway reply alone.

If a ping to another computer fails, the technician checks link lights, cable seating, IP configuration, routing, and whether the destination firewall allows ICMP. After an authorized change, the technician repeats the relevant tests and records the corrective action and retest result.
