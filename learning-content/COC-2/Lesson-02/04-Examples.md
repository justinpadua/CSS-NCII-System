# COC 2 — Lesson 2: Network Installation and Configuration

## Examples

### Install and verify a lab network connection

The instructor approves a short cable route from a workstation to a lab switch. The trainee measures the route, terminates both ends using the same approved pinout for a straight-through cable, and tests the wire map before connecting devices. The trainee labels both ends and records the switch port.

On an authorized Windows client, the trainee selects DHCP unless the network administrator has supplied approved static settings. The trainee checks the address, subnet mask, gateway, and DNS values with ipconfig /all. On a lab router, the administrator changes default credentials, selects supported wireless security, and uses a unique passphrase. The trainee records only non-secret settings; passwords are never written in the lab report.
