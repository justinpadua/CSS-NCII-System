# COC 2 — Lesson 2: Network Installation and Configuration

## Definition of Terms

- **T568A / T568B:** Common balanced-cabling pinout conventions. Use the site's specified scheme consistently.
- **Straight-through patch cable:** A cable terminated with the same pinout at both ends.
- **Crossover cable:** A cable with different transmit/receive pair mappings at opposite ends for compatible interfaces; Auto-MDIX often makes one unnecessary on modern equipment.
- **8P8C modular plug:** The eight-position/eight-contact connector commonly called an RJ-45 plug in Ethernet contexts.
- **Cable tester:** A tool that checks wire mapping and common continuity faults; a basic tester does not certify category performance.
- **IP address:** An address used to identify an interface on an IP network.
- **Subnet mask:** An IPv4 setting that identifies the network and host portions of an address.
- **Default gateway:** The router address a client uses to reach other networks.
- **DHCP:** Dynamic Host Configuration Protocol, which leases IP configuration to clients.
- **DNS:** Domain Name System, which resolves names to IP information.
- **SSID:** The name used to identify a wireless network.
- **WPA2-Personal / WPA3-Personal:** Wi-Fi security modes; select the strongest mode supported by the network's devices and policy.
- **WAN / LAN:** Router interfaces or network sides associated with the upstream network and local network respectively.
