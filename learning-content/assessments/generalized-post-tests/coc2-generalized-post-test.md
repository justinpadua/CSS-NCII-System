## Questions

### 1. (Easy)
Which device primarily forwards traffic between different IP networks?
- A. Patch panel
- B. Keyboard
- C. Router
- D. Cable tester


### 2. (Easy)
What does DHCP commonly provide to a client automatically?
- A. A permanent computer repair
- B. IP configuration such as an address, subnet mask, gateway, and DNS information
- C. A new network cable
- D. An encrypted backup of all files


### 3. (Easy)
Which command displays Windows IP configuration details?
- A. `ipconfig /all`
- B. `format`
- C. `diskpart`
- D. `dir`


### 4. (Easy)
What does a cable tester help check on a terminated Ethernet cable?
- A. Wire continuity and, depending on the tester, pair or pin mapping faults
- B. Whether a domain name resolves
- C. Whether an application server is licensed
- D. The internet provider's billing status


### 5. (Moderate)
Which topology connects endpoint devices to a central switch, making a single endpoint-link fault easier to isolate?
- A. Bus topology
- B. Ring topology
- C. Star topology
- D. Point-to-point serial chain


### 6. (Moderate)
A workstation needs a manually assigned address. What must be checked before assigning it?
- A. That it matches another computer's address
- B. That it is outside every permitted subnet
- C. The monitor resolution
- D. The approved subnet plan and DHCP scope, to avoid an address conflict


### 7. (Moderate)
A technician can ping a server by IP address but not resolve its hostname. Which service should be investigated first?
- A. DHCP lease duration only
- B. DNS configuration or name records
- C. Cable color
- D. Monitor driver


### 8. (Moderate)
Which wireless security choice is generally appropriate for a current home or small-office network when devices support it?
- A. Open Wi-Fi
- B. WEP
- C. TKIP-only mode
- D. WPA3-Personal, or WPA2-Personal with AES when WPA3 is not supported


### 9. (Difficult)
An authorized network inspection finds link lights on, valid IP configuration, a gateway ping reply, and failed DNS lookup. What is the best next diagnostic step?
- A. Check the configured DNS server and use `nslookup` to determine whether the query reaches and receives a valid response
- B. Re-terminate every cable without evidence
- C. Replace the switch immediately
- D. Disable all firewall protections


### 10. (Difficult)
A technician needs to test whether users can access a specific file-sharing service. Which approach provides the strongest relevant evidence?
- A. Ping the gateway once and assume file sharing works
- B. Test the required service from an authorized client and record the actual result, alongside supporting network checks
- C. Check whether the switch is new
- D. Run `ipconfig` and assume every application works
