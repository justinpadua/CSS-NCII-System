3.1 Internal Parts of the System Unit
The system unit is the main enclosure that contains the computer's internal components.


1.	Motherboard
2.	The motherboard is the main circuit board of the computer.
3.	It connects the CPU, RAM, storage devices, GPU, and other components.
4.	It provides communication pathways between hardware components.
5.	Important parts include CPU socket, RAM slots, PCIe slots, SATA connectors, and power connectors.





B. Central Processing Unit (CPU)
1.	The CPU processes instructions and performs calculations.
2.	It is often called the brain of the computer.
3.	It works with RAM and other components.
4.	It requires a cooling system to prevent overheating.





1.	Random Access Memory (RAM)
5.	RAM temporarily stores data and instructions being used.
6.	It allows the computer to access active data quickly.
7.	RAM is volatile, meaning its contents are lost when power is turned off.
8.	Common types include DDR3, DDR4, and DDR5.


D. Storage Devices
 
1.	HDD – stores data using magnetic disks.
2.	SATA SSD – stores data using flash memory.
3.	M.2 NVMe SSD – provides fast storage through the NVMe protocol.
4.	Storage devices retain files even when the computer is powered off.

E. Power Supply Unit (PSU)

1.	Supplies electrical power to the computer.
2.	Converts AC electricity into DC power.
3.	Provides power through connectors such as 24-pin motherboard, CPU power, SATA power, and PCIe power.
4.	A defective PSU may cause startup failure or unexpected shutdowns.

F. Graphics Processing Unit (GPU)

1.	Processes graphics and visual information.
2.	Helps run games, video editing applications, and 3D programs.
3.	May be integrated into the CPU or installed as a separate graphics card.



G. Cooling System

1.	Removes heat from the CPU and other components.
2.	Includes fans, heat sinks, and sometimes liquid cooling.
3.	Prevents overheating and performance reduction.


H. Computer Case

1.	Holds and protects the internal components.
2.	Provides mounting locations for the motherboard, PSU, drives, and fans.
3.	Helps manage airflow.






1.	CMOS Battery

1.	Maintains certain firmware settings and the real-time clock when the PC is disconnected from power.
2.	A weak battery may cause clock resets or settings loss on some systems.


3.2 How to Disassemble a System Unit PC (Step-by-Step Procedure)
Tools Needed
1.	Phillips screwdriver
2.	Flathead screwdriver (if required)
3.	Antistatic wrist strap
4.	ESD mat
5.	Small containers for screws
6.	Camera or smartphone for recording cable positions
7.	Soft brush or compressed air for cleaning
Procedure
1.	Prepare the Work Area
1.	Use a clean, dry, well-lit workbench.
2.	Place an ESD mat on the work surface.
3.	Organize tools and screw containers.
2.	Shut Down the Computer
1.	Save all work.
2.	Shut down the operating system.
3.	Turn off the PSU switch if present.
3.	Disconnect All Cables
1.	Unplug the power cable.
2.	Disconnect monitor, keyboard, mouse, USB devices, and network cables.
3.	Follow the vendor-documented service procedure and wait the specified time. Unplugging a computer does not make the inside of a power supply safe; never open a PSU enclosure.
4.	Open the Computer Case
1.	Remove the side-panel screws.
2.	Slide or lift the panel according to the case design.
3.	Place the panel in a safe location.
5.	Use ESD Protection
1.	Wear a properly grounded antistatic wrist strap.
2.	Handle components by their edges.
3.	Avoid touching contacts and exposed circuitry.
6.	Disconnect Internal Cables
1.	Disconnect motherboard power cables.
2.	Disconnect SATA data and power cables.
3.	Disconnect front-panel cables and fan cables as needed.
4.	Take pictures before removing connections.
7.	Remove Expansion Cards
1.	Unscrew the GPU or other expansion cards.
2.	Release the PCIe slot latch carefully.
3.	Lift the card straight out.
8.	Remove RAM Modules
1.	Release the RAM slot clips.
2.	Hold the module by its edges.
3.	Lift it carefully from the slot.
9.	Remove Storage Devices
1.	Unscrew the HDD or SSD mounting screws.
2.	Disconnect cables.
3.	Place the storage device in an ESD-safe container.
10.	Remove the CPU Cooling System
1.	Follow the cooler manufacturer's procedure.
2.	Disconnect the fan cable.
3.	Loosen mounting screws gradually and evenly.
4.	Carefully remove the cooler.
5.	Do not pull forcefully or twist in a way that may damage the CPU socket.
11.	Remove the CPU (If Necessary)
1.	Release the socket locking mechanism.
2.	Lift the CPU by its edges.
3.	Avoid touching pins or contact pads.
4.	Store in a protective CPU container.
12.	Remove the PSU
1.	Disconnect remaining PSU cables.
2.	Remove the mounting screws.
3.	Carefully slide out the PSU.
13.	Remove the Motherboard
1.	Remove the motherboard mounting screws.
2.	Lift the motherboard carefully.
3.	Place it on an ESD-safe surface.
14.	Organize the Components
1.	Label the parts.
2.	Store screws separately.
3.	Inspect components for visible damage.

3.3 How to Assemble a System Unit PC (Step-by-Step Procedure)
Tools Needed
1.	Phillips screwdriver
2.	ESD wrist strap
3.	ESD mat
4.	Thermal paste, when needed
5.	Cable ties or cable management straps
6.	Component manuals
Procedure
1.	Prepare the Work Area
1.	Clean the workbench.
2.	Use ESD protection.
3.	Check all parts for compatibility.
2.	Install the CPU
1.	Open the CPU socket.
2.	Align the CPU using the orientation marker.
3.	Place it gently into the socket.
4.	Lock the socket according to the motherboard instructions.
3.	Install RAM
1.	Check the recommended RAM slots in the motherboard manual.
2.	Align the notch.
3.	Press evenly until the retaining clips lock.
4.	Install the CPU Cooler
1.	Apply thermal paste if the cooler does not have pre-applied paste.
2.	Mount the cooler according to its manual.
3.	Connect the CPU fan to the CPU_FAN header.
5.	Prepare the Computer Case
1.	Install motherboard standoffs in the correct positions.
2.	Install the I/O shield if the board requires a separate one.
3.	Ensure no extra standoffs are touching the motherboard.
6.	Install the Motherboard
1.	Align the motherboard with the case.
2.	Place it onto the standoffs.
3.	Secure it with screws without overtightening.
7.	Install the PSU
1.	Position the PSU according to the case design.
2.	Secure it using screws.
3.	Route the power cables neatly.
8.	Install Storage Devices
1.	Mount the SSD or HDD.
2.	Connect SATA data and power cables if required.
3.	M.2 drives should be installed in the correct slot and secured with the proper screw.
9.	Install the GPU
1.	Insert the GPU into the correct PCIe slot.
2.	Secure it to the case.
3.	Connect required GPU power cables.
10.	Connect Power Cables
1.	Connect the 24-pin motherboard power cable.
2.	Connect the CPU power cable.
3.	Connect SATA power to appropriate devices.
4.	Follow the PSU manufacturer's cable compatibility guidance.
11.	Connect Front-Panel Cables
1.	Connect power switch, reset switch, LEDs, front USB, and audio.
2.	Use the motherboard manual for pin locations.
12.	Check Cooling and Cable Management
1.	Ensure fans are connected.
2.	Keep cables away from fan blades.
3.	Check that all components are firmly seated.
13.	Perform Initial Testing
1.	Connect monitor, keyboard, and power cable.
2.	Turn on the computer.
3.	Check for POST and BIOS/UEFI access.
4.	Confirm that CPU, RAM, and storage are detected.
14.	Close the Case
1.	After successful testing, install the side panel.
2.	Reconnect peripherals and prepare for software installation.

3.4 How to Troubleshoot a Malfunctioning Computer System
Troubleshooting is the systematic process of identifying and correcting computer problems.

A. Common Computer Problems and Solutions
Problem	Possible Cause	Troubleshooting
Computer does not turn on	Power cable, PSU, or motherboard issue	Check outlet, cable, PSU switch, and connections
No display	Monitor cable, GPU, RAM, or monitor issue	Check display input and reseat components if appropriate
Computer restarts repeatedly	Overheating, unstable power, or RAM problem	Check temperatures, power connections, and memory
Computer is slow	Low RAM, full storage, malware, or background processes	Check task manager, storage space, and security scan
No sound	Audio driver or output device issue	Check audio settings and driver
No internet	Network cable, Wi-Fi, driver, or router issue	Check network connection and adapter settings
Blue Screen	Driver, hardware, or software error	Record error code and check logs and recent changes
Overheating	Dust, poor airflow, or cooling problem	Inspect fans and clean cooling system safely
B. Troubleshooting Procedure
1.	Identify the problem.
2.	Ask the user about symptoms and recent changes.
3.	Check power and external connections.
4.	Observe error messages or diagnostic indicators.
5.	Identify possible causes.
6.	Test one possible cause at a time.
7.	Apply the appropriate solution.
8.	Verify that the computer works properly.
9.	Document the repair and findings.
