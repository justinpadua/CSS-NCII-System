# COC 1 — Lesson 2: Elements of Computer Systems

## Activity

LESSON 2 – ACTIVITY: SORT AND SYSTEM

**Learning objective:** Classify computer-system elements and connect common components with their functions.

**Materials:** Worksheet and pen. A computer or component picture is optional. No disassembly is required.

Practice identifying the parts and elements of a computer system.

How to use: click each gray field in Microsoft Word to pick an answer from the drop-down list, tick a box, or type your response.

Part A – Classify It

Choose the category of each item.  Word bank: Application software • Dataware • Firmware • Hardware • Peopleware • System software

1. A keyboard used to enter a report.
2. Windows managing memory, files, and devices.
3. A word processor used to write the report.
4. The student who uses and saves the report.
5. The saved report file.
6. UEFI code used to initialize hardware during startup.

Part B – Match the Component

Choose the component that performs each function.  Word bank: CPU • Cooling system • GPU • Motherboard • PSU • RAM

1. Executes general-purpose instructions and calculations.
2. Temporarily holds working data and instructions currently in use.
3. Converts incoming AC power into DC outputs used by system components.
4. Processes graphics and visual workloads.
5. Moves heat away from components using parts such as a cooler and fans.
6. Connects components and provides communication pathways between them.
