# COC 1 — Lesson 2: Elements of Computer Systems

## Examples

### A student saves a report

A student types a report using a word processor and saves it to an SSD.

- Peopleware: the student who operates the computer.
- Hardware: keyboard, CPU, RAM, monitor, and SSD.
- System software: the operating system manages devices and provides services to programs.
- Application software: the word processor helps create the report.
- Dataware: the report's text, images, and saved file.

If the report cannot print, the technician checks the printer connection and operating-system device status before changing settings. The saved report remains data; it is not hardware or software.
