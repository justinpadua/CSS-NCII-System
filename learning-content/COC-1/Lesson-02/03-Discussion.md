# COC 1 — Lesson 2: Elements of Computer Systems

## Discussion

### 2.1 The elements work together

A computer system includes physical equipment, programs, people, and data. Each element has a different role, and the system is useful when they work together.

| Element | Meaning | Example |
|---|---|---|
| Hardware | Physical parts that can be touched | CPU, RAM, SSD, keyboard, monitor, printer |
| Software | Programs and instructions | Windows, Linux, a word processor, a browser |
| Peopleware | People who use, support, or manage a system | Student, computer technician, system administrator |
| Dataware | Data and information stored or processed | Documents, inventory records, student files, images |

Example: A student uses a keyboard (hardware) to enter a report in a word processor (software). The student (peopleware) creates text and saves it as a file (dataware) on an SSD (hardware).

### 2.2 System software and application software

System software manages hardware or provides a platform for applications. It includes:

- **Operating system:** manages processes, memory, files, devices, and the user interface. Examples include Windows and Linux distributions.
- **Device driver:** allows an operating system to communicate with a particular device, such as a printer, graphics adapter, or network adapter.
- **Utility software:** performs support tasks such as backup, security scanning, or disk maintenance. Use tools from trusted publishers and follow organizational policy.
- **Firmware:** low-level software stored on a device that helps control or initialize hardware. BIOS/UEFI firmware is used during system startup.

Application software helps a user complete a specific task. Examples include a word processor for documents, a spreadsheet for calculations, a browser for web access, and an image editor for graphics.

### 2.3 How they depend on one another

When a user saves a document, the person operates an application. The operating system coordinates CPU, RAM, and storage. Hardware carries out processing and stores the file as data. A missing driver can prevent a device from working correctly; unavailable storage can prevent a file from being saved. Diagnose the affected element before replacing or reinstalling anything.

### 2.4 Basic troubleshooting approach

1. Ask the user what they were doing and what happened.
2. Identify which device, program, or data is affected.
3. Check simple causes such as power, connection, available storage, and clear error messages.
4. Make one authorized change at a time and record it.
5. Verify the result with the user or a relevant functional check.

Protect personal and organizational data. Do not copy or disclose records unless authorized.
