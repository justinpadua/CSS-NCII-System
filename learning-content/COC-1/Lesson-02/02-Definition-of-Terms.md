# COC 1 — Lesson 2: Elements of Computer Systems

## Definition of Terms

- **Computer system:** Hardware, software, people, and data working together to process information.
- **Hardware:** Physical components such as the CPU, RAM, storage, monitor, and keyboard.
- **Software:** Programs and instructions that run on a computer.
- **Peopleware:** People who use, manage, maintain, or develop computer systems.
- **Dataware:** The data and information a system stores, processes, or manages.
- **Central processing unit (CPU):** The processor that executes instructions and performs general-purpose calculations.
- **Random access memory (RAM):** Volatile working memory that holds data and instructions in use; its contents are lost when power is removed.
- **Storage device:** Non-volatile hardware, such as an HDD or SSD, that retains data when the computer is powered off.
- **Power supply unit (PSU):** A component that converts AC input into DC outputs required by computer components.
- **Graphics processing unit (GPU):** A processor that handles graphics and parallel workloads; it may be integrated or a separate card.
- **Operating system:** System software that manages computer resources and provides services for applications.
- **Application software:** Software designed for user tasks, such as word processing, calculation, or image editing.
- **Utility:** Software that performs maintenance, monitoring, backup, or protection functions.
- **Firmware:** Software used to control or initialize a hardware device, such as motherboard UEFI firmware.
