# COC 1 — Lesson 5: Installation of System and Application Software

## Examples

### Install an operating system on a lab computer

The instructor assigns a test computer whose data may be erased. Before installation, the trainee records the computer model and disk layout, confirms authorization, backs up any required files, and identifies the intended target drive by model and capacity. The trainee boots trusted installation media in the intended firmware mode, follows the operating-system instructions, and does not delete partitions on other drives.

After setup, the trainee applies updates and installs drivers from the computer or component manufacturer's support source. The trainee checks Device Manager, network, sound, display, storage, restart behavior, and required applications, then records the result and any unresolved issue. UEFI commonly pairs with GPT for Windows boot, but follow the target system and operating-system guidance rather than treating one layout as universal.
