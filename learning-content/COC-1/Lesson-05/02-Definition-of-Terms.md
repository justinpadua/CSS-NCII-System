# COC 1 — Lesson 5: Installation of System and Application Software

## Definition of Terms

- **BIOS:** Basic Input/Output System, legacy firmware used to initialize hardware and start a boot process.
- **UEFI:** Unified Extensible Firmware Interface, a modern firmware environment used to initialize hardware and start an operating system.
- **Boot order:** The sequence in which firmware checks available devices for boot software.
- **Secure Boot:** A UEFI feature that verifies boot components against trusted signatures according to configured policy.
- **Installation media:** An authorized USB, disc, or other source used to install an operating system.
- **Partition:** A defined region of a storage device.
- **Volume:** A storage area formatted with a file system and made available to an operating system.
- **GPT / MBR:** Partitioning schemes commonly associated with UEFI and legacy BIOS boot respectively; follow the computer and operating-system instructions.
- **Format:** Prepare a volume with a file system. Formatting or deleting partitions can make data inaccessible or erase it.
- **Device Manager:** A Windows utility for viewing hardware devices and their reported status.
- **Backup:** A separate copy of important data that can be restored if the original is lost or changed.
- **Authorization:** Permission from the owner or responsible administrator before installing software or changing data.
