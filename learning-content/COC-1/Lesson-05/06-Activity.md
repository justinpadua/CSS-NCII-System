# COC 1 — Lesson 5: Installation of System and Application Software

## Activity

LESSON 5 – ACTIVITY: INSTALL AND CONFIGURE

**Learning objective:** Sequence an authorized operating-system installation and identify common firmware, disk, and driver terms.

**Materials:** Worksheet and pen. Optional instructor-prepared installation screenshots or a disposable lab computer and authorized installation USB. A paper plan is sufficient; do not erase a live student or customer disk.

Practice installing and configuring an operating system.

How to use: click each gray field in Microsoft Word to pick an answer from the drop-down list, tick a box, or type your response.

Part A – Order the Installation

Number the steps from 1 to 7 for this scenario: an instructor authorized a clean installation on a designated lab computer, and required files have been backed up.

- Select the confirmed target drive and install the operating system using its documented process.
- Boot from the trusted installation media in the appropriate firmware mode.
- Obtain authorization and back up required data; record the target computer and disk.
- Install required applications and document the work.
- Complete initial setup and create or use the authorized user account.
- Install required drivers and updates from trusted vendor or organizational sources.
- Set the USB as a temporary first boot choice in BIOS/UEFI when needed.

Part B – Match the Term

Choose the term that fits each description.  Word bank: BIOS/UEFI • Backup • Device Manager • Disk Management • Driver • Partition

1. Firmware interface that initializes hardware and selects a boot path.
2. A defined region of a storage device.
3. Windows utility for viewing and managing disks, partitions, and volumes.
4. Windows utility for viewing hardware devices and their reported status.
5. Software that lets an operating system communicate with a hardware device.
6. A separate copy of important data that can be restored.

Part C – After the Installation

Tick every task that belongs after installing the operating system.

Install the correct device drivers

Check network, audio, and display

Install needed applications

Document the installation

Delete the EFI or recovery partition

Skip the backup to save time

Part D – Troubleshoot It

A newly built PC will not boot from the USB installer.

List two things you would check or change.

**Steps:** Complete Parts A and B, then finish the existing after-install checklist and troubleshooting scenario. Do not change firmware security or storage mode without an authorized, documented reason. Do not recommend deleting EFI, recovery, or system partitions as routine cleanup. A live installation is not required.

**Expected output:** Seven-step installation order, six term matches, completed after-install checklist, and two safe USB-boot troubleshooting checks.
