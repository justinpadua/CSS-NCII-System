# COC 1 — Lesson 6: Computer Testing and Documentation

## Activity

LESSON 6 – ACTIVITY: PUSH IT, MEASURE IT

**Learning objective:** Plan a controlled component test, recognize observations requiring action, and document conclusions within the limits of the test evidence.

**Materials:** Worksheet and pen. Use instructor-provided sample results for paper simulation. Optional practical work requires an instructor-approved lab PC, monitoring and component-test utilities, saved work, and continuous supervision. Do not test a personal/customer computer or change voltage/overclock settings.

Practice stress testing and reporting.

How to use: click each gray field in Microsoft Word to pick an answer from the drop-down list, tick a box, or type your response.

Part A – Order the Stress Test

Number the steps from 1 to 7 in the correct order.

- Check the assembly, cooling, fans, and connections before testing.
- Start one appropriate component test while monitoring.
- Prepare a report with results and recommendations.
- Record observed peak temperatures and errors in the test log.
- Stop the workload when complete or immediately if a safety limit or problem occurs.
- Record hardware/software specifications and idle baseline readings.
- Monitor temperatures, errors, fan behavior, and stability continuously.

Part B – Match the Term

Choose the term that fits each description.  Word bank: Artifacts • Fault isolation • Idle temperature • Peak temperature • Test log • Thermal throttling

1. Performance reduction used to manage temperature or power conditions.
2. Unexpected visual corruption or defects during graphics output.
3. Temperature observed before the selected workload begins.
4. Highest temperature observed during the defined test interval.
5. Testing one likely cause/component at a time to narrow a fault.
6. Record of settings, duration, observations, results, and actions.

Part C – What Do You Do?

Choose the best response to each observation.  Word bank: Ignore the result • Report no issue observed under the tested conditions • Reseat or replace the RAM, then retest • Stop the test • Suspect a graphics problem

1. The test reaches the hardware manufacturer's limit, or cooling fails.
2. A GPU workload produces visible artifacts.
3. A memory diagnostic reports errors; after recording the result, shutting down/disconnecting power, and following the hardware procedure, an authorized technician is ready to check seating or isolate modules.
4. A test completes its selected duration with no reported errors. Describe only what was observed under those test conditions; do not claim permanent stability.

Part D – Write the Conclusion

Test data: CPU idle 40°C, peak 98°C, performance dropped after 5 minutes, no crashes.

Write a short conclusion and one recommendation.

For Part D, treat the provided readings as a paper interpretation case. Compare them with guidance for the exact CPU model and system; do not infer a universal failure limit from 98°C alone.

**Steps:** Complete the paper sequence, matching, and response selections. For optional practical testing, obtain instructor approval, save work, inspect cooling, record hardware/software and baseline readings, use one suitable workload, monitor continuously, and stop immediately for unsafe readings, errors, unusual noise/smell, artifacts, or instability. Follow manufacturer and tool guidance.

**Expected output:** Seven-step test plan, six term matches, four response selections, and a qualified conclusion/recommendation based on the given data or supervised observations. A completed paper simulation is sufficient; live stress testing is not required.
