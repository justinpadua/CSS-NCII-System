# COC 1 — Lesson 6: Computer Testing and Documentation

## Examples

### Record a controlled graphics test

A technician receives a desktop that restarts during a graphics workload. With permission, the technician records the model, hardware, software versions, and the reported symptom. Before testing, the technician checks fans, vents, power connections, and cooling, then opens a monitor and records baseline readings.

The technician runs a suitable graphics test under supervision and watches temperatures, errors, artifacts, and stability. The system restarts, so the technician stops the test instead of repeating it. The report records the test and settings, duration, observed readings, restart, corrective checks, and retest status. Temperature limits are checked against the exact component manufacturer's specifications; one reading is not a universal pass/fail rule.
